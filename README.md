**🎨 Virtual Art Gallery**

      A fully interactive 3D-inspired virtual art gallery experience that allows users to explore themed art rooms, upload their own artworks, and view them dynamically within realistic digital frames — all inside a smooth, animated virtual gallery environment.

      Designed to merge technology and creativity, this project delivers a museum-like feel in a web-based interface, with persistent artwork storage, automatic background music, and responsive animations powered by JavaScript and CSS transitions.

**Live Demo 👉** https://ala111205.github.io/Virtual-Gallery/

**🚀 Features:-**

**🎭 Core Gallery Features**

      🖼️ Three immersive eras (rooms) — Classical, Modern, and Digital — each displaying art collections in its own visual context.

      🪞 Upload your own artworks — users can add custom images with titles, artists, and category selection.

      💾 LocalStorage persistence — artworks remain visible even after refreshing or reopening the site.

      🔍 Interactive frame popups — clicking an artwork displays its title and artist dynamically in a styled popup overlay.

      🗑️ Delete feature — users can remove uploaded artworks instantly.

      📸 Automatic image resizing — uploaded images are resized to fit perfectly into digital frames.

.

**🌐 Advanced & Interactive Enhancements**

      🎧 Ambient background music — plays automatically when the user enters the gallery (and continues after reload).

      🔈 Music toggle button — user can manually mute or unmute background sound.

      🎞️ Smooth room navigation — forward and backward navigation between eras with zoom-in transitions.

      💡 Dynamic overlay forms — visually appealing modal-style form for adding new art pieces.

      🎨 Live-rendered frames — artworks appear dynamically in their corresponding category after form submission.

      🧠 Smart reload behavior — gallery reloads cleanly with preserved artworks and no default flicker.

      📱 Fully responsive layout — adapts to desktop, tablet, and mobile devices smoothly.

**🔔 Smart Interactivity**

      ⚙️ Click-based event system – everything (frames, icons, popups) responds to intuitive user interaction.

      🧩 Auto-handling popups – only one artwork popup appears at a time.

      🎛️ Realistic gallery transitions – background zoom and opacity effects simulate depth movement between rooms.

      🧹 Default art removal logic – dynamically clears sample artworks when user uploads begin.

**💾 Data Persistence**

      ✔️ LocalStorage Integration

      . Saves all artworks, including image data, title, artist name, and category.

      . Automatically reloads user artworks on every visit.

**⚙️ Tech Stack:-**

**🖥️ Frontend**

    **.** HTML5 – semantic and accessible structure for gallery layout.

    **.** CSS3 – animations, responsive grid design, and visual depth effects.

    **.** JavaScript (ES6) – dynamic DOM manipulation, event handling, localStorage, and image processing.

    **.** Canvas API – used internally to resize uploaded images to optimal frame fit.

    **.** Font Awesome – for intuitive icon add control.
